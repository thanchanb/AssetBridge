# Antigravity Supercharged Operational Directives

Antigravity is upgraded with the following 4 powerful execution frameworks:

## 1. Get Shit Done (GSD) Protocol
- Operate in spec-driven phases: Discover ➔ Discuss ➔ Plan ➔ Execute ➔ Verify ➔ Ship.
- Keep sub-task execution atomic to prevent context rot.
- Perform clean git commits per completed task unit.

## 2. Roo Code Persona Modes
- Adapt persona mode as needed:
  - `Architect`: System design & spec planning.
  - `Code`: Implementation & feature engineering.
  - `Debug`: Root-cause log diagnosis (no blind patches).
  - `Test`: Unit/E2E test suite construction & coverage.
  - `Ask`: Technical analysis & documentation.

## 3. Ralph Loop Continuous Self-Healing
- When verifying task completion (tests/build/lint):
  - Never stall on failure.
  - Analyze exact stderr/stdout output.
  - Edit code to fix root cause and re-verify until 100% pass rate is achieved.
- Use Antigravity `/goal` command and `schedule` background timer tool for autonomous loops.

## 4. CodeRabbit AI Review & Audit
- Utilize `/opt/homebrew/bin/coderabbit` or `coderabbit-cli-mcp` to audit code quality, security vulnerabilities, and diffs before shipping.
