# AssetBridge Level 6 User Outreach & Onboarding Plan 🚀

This document outlines the systematic community outreach, recruitment, and onboarding strategy designed to achieve and exceed **70+ active Preprod/Preview network testers** for AssetBridge.

---

## 🎯 Target Goal & Audience

- **Target Goal:** Onboard **70+ verified active users** on Cardano Preprod / Preview network.
- **Target Audience:** Midnight Network developers, Cardano ecosystem builders, Zero-Knowledge proof enthusiasts, privacy advocates, and Web3 beta testers.

---

- **Telegram:** Cardano Builders & Midnight Testnet Telegram groups.
- **Reddit:** `r/Cardano`, `r/MidnightNetwork`, `r/Web3Devs`.

### 3. Web3 & ZK Beta Testing Alpha Groups
- **X (Twitter):** Public testnet announcement threads tagging `@MidnightNtwrk` and `#MidnightHackathon`.
- **Guild.xyz / Zealy:** Simple onboarding quest directing users to test shielding/unshielding on Cardano Preprod and submit form feedback.

## 📝 Onboarding Instructions Provided to Testers

1. **Install Wallet Extension:** Download [Lace Wallet](https://www.lace.io/) or Eternl.
2. **Switch Network:** Toggle network setting to **Cardano Preprod** or **Preview Network**.
3. **Get Faucet Test ADA:** Request test tokens via the [Cardano Preprod Faucet](https://docs.cardano.org/cardano-testnets/tools/faucet/).
4. **Launch AssetBridge dApp:** Open [https://github.com/thanchanb/AssetBridge](https://github.com/thanchanb/AssetBridge) and run `npm run dev`.
5. **Execute Shielding Operation:** Bridge at least 5 tADA to sADA.
6. **Submit Feedback:** Click the embedded feedback panel or view the [Google Form Specification](https://github.com/thanchanb/AssetBridge/blob/main/docs/feedback-form-spec.md) to record your ratings, feedback, and wallet address.
