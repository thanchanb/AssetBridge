# AssetBridge — User Recruitment & Onboarding Strategy (Level 5)

This document outlines the onboarding strategy for recruiting testnet users to evaluate AssetBridge on the Midnight Preprod network.

## Onboarding Objectives

1. **Recruit Testnet Participants:** Engage community members across official Midnight Discord and developer forums.
2. **Collect Verifiable Feedback:** Guide testers to perform shielding interactions and submit ratings via [`src/components/Feedback.jsx`](../src/components/Feedback.jsx).
3. **Log Genuine Wallet Data:** Populate [`docs/PREPROD_USERS.md`](./PREPROD_USERS.md) with verified Midnight Preprod wallet addresses and transaction activity proofs.

## Target Community Channels

- **Midnight Developer Discord:** `#showcase` and `#feedback` channels.
- **Developer Documentation & GitHub:** Public repository links and issue tracker.
